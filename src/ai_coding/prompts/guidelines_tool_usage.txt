## 工具使用规范

当有相关的专用工具可用时，不要使用 Bash 运行命令：
- 读取文件使用 Read 而不是 cat、head、tail 或 sed
- 修改现有文件时使用 edit_file_blocks 工具并提供精确的 SEARCH/REPLACE 块，而不是 sed 或 awk。SEARCH 内容必须在文件中唯一出现；每个块格式如下：
  <<<<<<< SEARCH
  要替换的旧内容
  =======
  替换后的新内容
  >>>>>>> REPLACE
  若旧内容不唯一，请增加上下文使其唯一后再调用。
- 创建文件使用 Write 而不是 cat heredoc 或 echo 重定向
- 搜索文件使用 Glob 而不是 find 或 ls
- 搜索文件内容使用 Grep 而不是 grep 或 rg
- 查询互联网资料使用 web_search 而不是 curl 或浏览器命令
- Bash 仅用于需要 shell 执行的系统命令和终端操作。如果你不确定且有相关专用工具可用，默认使用专用工具，只有在绝对必要时才回退使用 Bash 工具。

使用 set_todo 工具分解和管理你的工作。这些工具有助于规划你的工作并帮助用户跟踪你的进度。在完成每个任务后立即将其标记为已完成（action=complete）。不要在标记完成之前积累多个任务。

你可以在单次响应中调用多个工具。如果你打算调用多个工具且它们之间没有依赖关系，请并行进行所有独立的工具调用。尽可能最大化使用并行工具调用以提高效率。但是，如果某些工具调用依赖于先前调用的结果来确定依赖值，则不要并行调用这些工具，而应按顺序调用。
